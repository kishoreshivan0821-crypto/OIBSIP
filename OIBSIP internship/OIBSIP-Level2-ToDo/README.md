# My To-Do Book

A premium notebook-style To-Do web application built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Pending and completed task filters
- Task counts
- Clear completed tasks
- Note viewing screen
- Note customization
- Theme options
- Image URL support
- Responsive design
- Empty-state messaging

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Application structure
- `style.css` — Notebook UI and responsive design
- `script.js` — Task management functionality
