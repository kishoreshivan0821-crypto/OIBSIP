# Login Authentication System

A client-side login authentication system built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- User registration
- Full name and email validation
- Password confirmation
- Password hashing using SHA-256
- Login authentication
- Invalid credential handling
- Session-based login state
- Protected dashboard
- Logout functionality
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API
- LocalStorage
- SessionStorage

## Project Structure

- `index.html` — Authentication interface
- `style.css` — User interface styling
- `script.js` — Registration, login and session functionality
