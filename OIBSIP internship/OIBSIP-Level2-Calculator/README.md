# Calculator

A responsive calculator web application built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Addition, subtraction, multiplication and division
- Decimal calculations
- Percentage
- Backspace
- Clear / AC
- Operator chaining
- Division-by-zero handling
- Calculation history
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Calculator structure
- `style.css` — Styling and responsive design
- `script.js` — Calculator functionality
